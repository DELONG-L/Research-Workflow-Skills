# Visual assets and sources / 视觉资源与来源

[English home](../README.md) · [中文首页](../README.zh-CN.md)

The covers use cool off-white, slate-blue, pale steel-blue, and restrained copper accents. Slate-blue organizes the text and file structures; copper draws attention to record marks and connection points. Regular book-serif typography in English, Songti in Chinese, and open margins keep the two independent skill areas legible.

封面使用冷白、石板蓝、浅钢蓝和少量铜橙。石板蓝组织文字与文件结构，铜橙提示记录标记与连接节点。英文采用常规书籍衬线字形，中文采用宋体，配合舒展的留白，让两项可独立使用的技能保持清楚的层次。

The upper row represents experiment planning, execution records, and evidence-linked results. The lower row represents an organized local research workspace. They do not imply that either skill depends on the other. These are conceptual illustrations, not application screenshots or experimental findings.

上方图示表示实验规划、执行记录与关联依据的结果，下方表示组织清楚的本地研究工作区。两者不表示技能之间存在强制依赖。封面属于概念示意，不是应用截图或实验研究结果。

The README record and directory examples follow the public [experiment record templates](../experiment-design-management/references/experiment-records.md) and [workspace contract](../research-workspace-governance/references/project-workspace-contract.md). No private research material or external photographs are used.

README 中的记录与目录示例依据公开的[实验记录模板](../experiment-design-management/references/experiment-records.md)和[工作区契约](../research-workspace-governance/references/project-workspace-contract.md)，未使用私人研究材料或外部摄影作品。
